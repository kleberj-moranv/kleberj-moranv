A group project using 2025 HMDA data from Virginia to analyze mortgage application outcomes and explore how predictive modeling can support portfolio allocation decisions.

A group operations analytics project that uses mathematical optimization to schedule movie scenes while considering actor holding costs, location transfers, and weather constraints.

**Tools:** Python, OR Tools, CBC, NumPy, MILP, scenario analysis
